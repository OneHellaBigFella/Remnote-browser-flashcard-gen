# Flashcard Generator Importer (RemNote plugin)

Receives flashcards from the Flashcard Generator browser extension and writes them into today's Daily Document, under a `📥 <page title>` source rem.

Commands (Omnibar / `/`):
- **Flashcard Generator: insert sample cards into Daily Document** - checks that the plugin works.
- **Flashcard Generator: import cards from clipboard into Daily Document** - for the mobile / PWA path.

Settings: **Pairing token** (copy into the extension's options).
